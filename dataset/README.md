# Prakhar Sharma profile dataset

This dataset is the evidence-first input for LinkedIn Indo's persona and resume
workflows. It contains public-professional information only. Private records,
credentials, passwords, government identifiers, and sensitive academic files are
intentionally excluded.

`persona.json` contains normalized positioning and writing preferences.
`posts.json` contains only verified post exports or clearly labelled user drafts.
`evidence.json` maps resume claims back to local source material.

The LinkedIn profile scan could not be completed in this environment because
LinkedIn returned HTTP 999. Add LinkedIn's own data export under `samples/` only
after reviewing it and removing private messages, contact lists, and unrelated
personal data.
