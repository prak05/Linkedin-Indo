# Online Privacy & Security Suite: IBM Watson NLU Cyber Threat Detection

**Domain:** Cybersecurity, Natural Language Understanding, Web Security  
**Repository:** [https://github.com/prak05/online-privacy-security](https://github.com/prak05/online-privacy-security)  

---

## 📌 Executive Overview
Phishing campaigns, credential harvesting vectors, and deceptive social engineering scams frequently evade static rule-based firewalls by utilizing evasive natural language phrasing.

**Online Privacy & Security Suite** is a threat intelligence tool built with JavaScript and IBM Watson Natural Language Understanding (NLU) that analyzes web content, email text, and URL structures to flag privacy violations and cyber threats.

---

## ⚡ Technical Architecture & Security Stack
- **Cognitive NLP Engine:** IBM Watson Natural Language Understanding (sentiment, emotion, entity, and semantic category extraction).
- **Heuristic Classifier:** Custom URL lexical analysis (entropy, IP-based domains, excessive subdomains, brand typosquatting).
- **Frontend & Integration:** JavaScript (Node.js & browser client), RESTful API communication.

---

## 📊 Key Highlights & Defense Capabilities
- **Automated Phishing Score:** Combines semantic threat markers with domain reputation scores for composite risk ratings.
- **Privacy Policy Parser:** Summarizes lengthy corporate privacy agreements into actionable risk breakdowns.
- **Lightweight Browser Integration:** Deployable as an extension to safeguard non-technical end users in real time.
