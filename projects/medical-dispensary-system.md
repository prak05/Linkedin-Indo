# Medical Dispensary System: Enterprise Clinical Pharmacy & Inventory Core

**Domain:** Healthcare Information Systems, Enterprise Desktop Software, Database Engineering  
**Repository:** [https://github.com/prak05/MedicalDispensarySystem](https://github.com/prak05/MedicalDispensarySystem)  

---

## 📌 Executive Overview
Hospital pharmacies and independent medical dispensaries require strict tracking of drug expirations, batch numbers, prescription dispensations, and supplier transactions to guarantee patient safety and regulatory compliance.

**Medical Dispensary System** is a 3-tier enterprise desktop management platform engineered in Java and SQL, providing end-to-end inventory control, role-based pharmacist access, and automated receipt generation.

---

## ⚡ Technical Architecture & Desktop Stack
- **UI & Presentation Layer:** Java Swing (AWT/Swing MVC architecture), customized desktop panels, role-based views.
- **Data Access Layer:** JDBC (Java Database Connectivity) with prepared statements ensuring SQL injection immunity.
- **Database Engine:** MySQL / Oracle relational schemas with foreign key integrity and transactional isolation.

---

## 📊 Key Highlights & Inventory Safety
- **Expiry Date Alerting:** Automated flagging of upcoming expiring pharmaceutical batches to prevent wrongful dispensation.
- **Low-Stock Auto-Reorder Triggers:** Dynamic notification thresholds per medication category.
- **Audit-Compliant Transaction Ledgers:** Full traceability for scheduled drug inventory and dispensing physicians.
